# Slides Package

Carpeta armada para presentar los benchmarks del Ejercicio 3.

## Contenido

- `00_overview/`: comparativas globales entre runs.
- `1_baseline/`: evidencia completa del run `1-Baseline`.
- `2_weighted_loss/`: evidencia completa del run `2-Weighted-Loss`.
- `3_weighted_sampling/`: evidencia completa del run `3-Weighted-Sampling`.
- `4_synthetic_balancing/`: evidencia completa del run `4-Synthetic-Balancing`.
- `5_smote/`: evidencia completa del run `5-SMOTE`.

## Qué tiene cada run

- hiperparámetros usados
- resumen de métricas train / validation / test
- JSON completo del resultado
- curva de entrenamiento
- matriz de confusión
- saliency map y visualización de pesos si existen
